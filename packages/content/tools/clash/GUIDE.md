# 標註指引：句子講緊乜方向（同章矛盾偵測用）

每批係一個 JSON array，每項 `{ "i": 編號, "t": 句子, "ch": [會出現喺邊幾章] }`。章名係宮名（命宮、兄弟、夫妻、子女、財帛、疾厄、遷移、僕役、官祿、田宅、福德、父母）或者「這十年」「這一年」。

目的：之後喺同一章入面，搵出「同一條軸、同一個對象、方向相反」嘅兩句。所以你要標嘅係**呢句對讀者斷言咗乜方向**，唔係評價寫得好唔好。

## 軸（只用呢十條；`+` / `-` 嘅意思如下）

| 軸 | + | - |
|---|---|---|
| 關係 | 融洽、和睦、感情深、得寵愛、相處得來 | 不和、疏遠、隔膜、緣淺、摩擦、爭執、合不來 |
| 助力 | 得到幫助、提攜、貴人、得力、被信任 | 孤立、少人照應、助力少、被算計、被拖累 |
| 順逆 | 順利、有福、得利、得財、安穩 | 挫折、阻滯、多是非、不安、功虧一簣、破耗 |
| 變動 | 安定、少搬、守在原地、不輕易變 | 多變、常搬、常換、走動、離鄉 |
| 合作 | 宜合作、一起做事、合夥順 | 宜各自、獨立做、不宜合夥 |
| 主動 | 出面、直說、主導、帶頭、爭取 | 退讓、不出頭、收著不說、遷就、順從 |
| 嚴寬 | 要求嚴、標準高、管得緊 | 寬鬆、容許、開不了口、放手 |
| 快慢 | 快、衝、即刻動手、果斷 | 慢、求穩、拖、謹慎、遲遲 |
| 聚散 | （錢）守得住、積聚、存錢 | （錢）散、守不住、花得快、起伏大 |
| 早晚 | 早發、起步早／省力、少年得志 | 晚發、起步晚、中年後才 |

## 對象（`o`）

斷言係講邊個／邊方面：`你`（讀者本身的性格、做法）、`伴侶`、`父母`、`母親`、`父親`、`長輩`、`上司`、`兄弟姊妹`、`朋友`、`同事`、`下屬`、`後輩`、`子女`、`錢`、`工作`、`住處`、`在外`、`身心`。
- 「你和父母不和」→ 軸 關係，對象 父母。
- 「你和長輩、上司的關係一般良好」→ 兩項：關係 `+` 長輩、關係 `+` 上司。
- 「你在外容易孤立」→ 助力 `-`，對象 `在外`。
- 講讀者自己嘅性格、做事方式 → `你`。

## 範圍（`s`）

- `g` 一般：冇講條件（「天同在遷移宮，你出門在外一般是得福的」都係 g，因為「天同在遷移宮」係呢格本身）。
- `c` 帶條件：句入面明講要見到某星、化忌、煞、某地支才成立（「同宮有鈴星，在外多挫折」「巨門化忌，你的家宅不安」「見左輔、右弼，⋯」）。
- `p` 時期：講緊某段時間（「這十年」「這一年」「感情上比較甜」喺運限章）。

## 規則

- 一句可以有零至三項標註。**冇明確方向就唔好標**（大部分描寫性格細節、建議、比喻嘅句都冇）。
- 建議句（「⋯比較好」「記得⋯」「先⋯」）通常唔標，除非佢同時斷言咗方向（「晚一點結婚對你比較好」→ 早晚 `-` 伴侶）。
- 兩面都講（「表面融洽，心裡卻各有顧忌」「有隔膜也能互相諒解」「雖勞心卻能得財」）→ 唔標，或者只標佢最後落嘅結論。
- 否定要睇清楚：「不易融洽」係 關係 `-`；「不輕易搬」係 變動 `+`。
- 唔確定就唔標。寧缺勿濫。

## 輸出

寫一個 JSON 檔（路徑見你嘅任務），格式：

```json
{ "batch": "01", "rows": [ { "i": 123, "a": [["關係", "-", "父母"]], "s": "c" } ] }
```

- `rows` 只放有標註嘅句（冇標註嘅唔使列）。
- `a` 每項 `[軸, "+"或"-", 對象]`，軸同對象只可以用上面列出嘅字。
- 完成後用 Python 或 node 驗證 JSON 讀得返，並報告：總句數、有標註句數、每條軸幾多項。
