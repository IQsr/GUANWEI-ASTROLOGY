# 起草判斷卡：主星守事業宮（官祿宮）（給 Codex）

你要將王亭之《中州派紫微斗數深造講義》事業宮篇嘅原文段落，轉成「判斷卡」JSON。只輸出一個 JSON 陣列（唔好 markdown、唔好解釋），每個元素一張卡。

## 輸入
- 原文段落檔（每行：段落id ⇥ 頁 ⇥ 原文，簡體）：見 prompt 指定嘅檔案。
- 例子：tmp/synth-draft/examples.json（已審核嘅**財帛**卡，跟足佢嘅格式同語氣；你要寫嘅係事業宮，宮名換成「官祿」）。

## 卡嘅欄位（全部必填，除非寫明可選）
- id："syn.career.<星拼音>.<短名>"，全部小寫 ascii，短名用 a-z0-9-（例：syn.career.ziwei.ziwu-alone）。星拼音：ziwei tianji taiyang wuqu tiantong lianzhen tianfu taiyin tanlang jumen tianxiang tianliang qisha pojun。
- chapter："事業"
- group："<星>事業.<小題>"，小題用 2–4 個中文字（行業、職位、創業、合作、變動、挫折、化、競爭、時序…）。同一個因素嘅卡用同一個 group。
- specificity：原文講明宮位（子午、卯酉…）或者雙星組合 → "system"；淨係講「某星守事業宮」嘅通則 → "general"。
- polarity："吉" / "凶" / "中"。
- weight：原文用「主、決主、必、則」→ "斷"；「往往、易、宜、一般、多」→ "傾"；「樞紐、可視為」→ "提"。
- seat："seated"
- layer：["natal"]
- when：條件（見下面條件語言）。**原文句子嘅每一個前提都要寫入條件**；寫唔到嘅前提（例如天刑、天姚、桃花、陰煞、天巫、大耗、龍池鳳閣、天月、恩光天貴、命宮以外宮位嘅複雜配合）→ **成張卡唔好寫**。
- alone（可選）：{"star": 星, "in": {"name": "官祿"}}：該星係事業宮唯一主星（原文「獨坐」）。
- requires（可選）：額外條件，通常係 {"star": 星, "in": {"name": "官祿"}}。
- none（可選）：原文明寫嘅排除條件。
- bright（可選）：{"star": 星, "levels": ["陷"]} 之類，原文講廟、旺、陷先用。
- because：一句盤面事實，用「你的事業宮…」開頭，講出觸發條件（可以用 {branch} 代宮支）。只講條件，唔講結論。
- claim：一句結論，繁體中文，用「你…」直接講，講原文嘅意思，唔加原文冇嘅嘢。
- advice（可選，少用）：{"text": 做法, "why": 點解係呢個盤}。只喺原文直接推得出具體做法先寫。
- source：段落 id（例 "wtz.deep.p521.b002"）。
- quote：該段落原文嘅**逐字子串**（簡體，連標點照抄；揀支持 claim 嗰句，唔好改字、唔好補字）。

## 條件語言（只准用以下原子）
- {"star": "紫微", "in": {"name": "官祿"}}：星坐本命事業宮（宮名一定寫「官祿」）
- {"star": "紫微", "at": ["子","午"]}：星坐呢幾個地支
- {"star": "武曲", "hua": "祿"}：本命四化（祿／權／科／忌）
- {"together": ["紫微","天府"]}：同宮
- {"opposite": ["紫微","貪狼"]}：對宮
- {"meets": "紫微", "stars": ["左輔","右弼"], "reach": "sanfang", "op": "gte", "n": 2}：該星所在宮嘅同度（same）／三方四正（sanfang）／左右夾（jia）見到幾多粒。stars 可以用 "化祿" "化權" "化科" "化忌" 表示本命四化。op 預設 gte，n 預設 1。
- {"sanfangOf": {"name": "官祿"}, "contains": "祿存"}
- {"sanfangOf": {"name": "官祿"}, "count": "malefic", "op": "gte", "n": 1}（count 可以係 benefic／malefic）
- {"jia": "天相", "sides": [["化忌"], ["擎羊"]]}：左右兩邊夾
- {"deLu": "七殺"}：該星三方四正見祿存或化祿
- {"all": [...]}, {"any": [...]}, {"not": {...}}
星名只可以用：十四主星、左輔 右弼 文昌 文曲 天魁 天鉞、擎羊 陀羅 火星 鈴星 地空 地劫、祿存 天馬。
「煞」= malefic；「吉曜／輔佐」= benefic；「羊陀」= 擎羊、陀羅；「火鈴」= 火星、鈴星；「空劫」= 地空、地劫；「昌曲」= 文昌、文曲；「魁鉞」= 天魁、天鉞；「祿馬」= 祿存（或化祿）同天馬。

## 寫作規則
1. 每條卡一定要有 when 或 alone，而且條件一定要包含「該星坐官祿」（可以放 when、requires 或 alone）。
2. 唔好用「原書」「王亭之」等字眼；唔好用「最」「一生最」「最順」等最高級，除非原文本身就係比較（例如「最利財源的星系」可以寫「在…之中最利財源」）。
3. 唔好假設讀者經歷（唔好寫「你曾經」「那次」「你剛」）；唔好自創比例或數字（原文有嘅年歲可以照用）。
4. 原文係「若…則…」，卡就係 when=若、claim=則。一段有幾個分支就拆成幾張卡。
5. 原文講「命宮」「福德」「財帛宮」等其他宮位嘅條件，而條件語言寫唔到 → 唔好寫。
6. 每粒星大約 6–14 張卡；先寫最具體、最常見、最有實際意思嘅分支。冇實質內容嘅段落（標題、例子敘述）跳過。
7. claim 要短（一至兩句），平實，似同讀者講嘢。

8. **唔好用原文冇嘅條件頂替寫唔到嘅前提。** 例如原文前提係「為人正直」「物質性重」「格局高」「性質優良」呢類本質判斷，條件語言寫唔到 → 成張卡唔好寫；**唔准**改用某個化曜或吉曜數量去代替。
9. 列表式段落：結論喺標題或者上一段（唔喺 quote 嗰段原文入面）→ 唔好寫。quote 一定要喺 source 嗰段入面，而且 quote 本身要撐得起 claim。
10. 原文講「大運／流年／運限」應期嘅句，唔好寫（另行處理）。

## 額外欄位 yearClaim（一定要有）
- 如果呢個判斷係**事件或者狀況**（例如挫折、變動、升遷、糾紛、競爭、失業、合作破裂），寫一句「今年…」嘅一年內講法，例如 claim「你一生事業至少有一次重大挫折」→ yearClaim「今年事業上要防出現較大挫折」。
- 如果係**性格、才能、行業適合度、一生時序**（例如「宜任職大機構」「適合從事策劃」「晚年才成功」）→ yearClaim 寫 null。
- yearClaim 唔可以用「必」「決」「一定」「最」。
