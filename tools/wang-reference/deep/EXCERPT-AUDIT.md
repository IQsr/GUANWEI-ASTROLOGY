## 範圍與使用方式

- 逐項比較原頁／前後段、現有中文引文消費句及明載條件，不是命理效力或命盤實證。
- 六十星系重點核 plain.basis、plain.lean（含平衡），及逐項指出的其他中文欄；core/trine/lean舊稿、全部評分rules與英文未整套核驗。
- branch基礎來源會在citation.ts連到星系plain.basis與兩端lean，生成清單會補此間接使用，不把basis只看成沒文案。
- plain/palace的source只為summary背書，watch未因此獲核。
- lean等程式分數對原文格局的映射未驗證；原文條件可支持某句，不等於程式已替某盤判對。
- metadata_only指本次所核核心文意可保留、主要修定位／摘錄格式，仍受共同範圍與逐項修飾所限。
- expand_evidence指已在所列完整上下文找到相應支持，但現摘引不足或需保留修飾；按建議拆分補引，未等於可直接標已核。
- revise_copy／fix_conditions為目前掛源不足以支持原樣文案或觸發條件，按具體缺口刪改；不代表已證全書其他地方絕無相似說法。
- hold_source保留本機PDF歧義；未對其他版本，不能以推測作原文校定。
- 來源正文只在忽略tmp；追蹤檔保留摘要、段號、指紋與現有專案文案快照。

```powershell
python tools/wang-reference/excerpt_audit.py show --id deep.星系06.8 --source
python tools/wang-reference/excerpt_audit.py search --verdict fix_conditions
python tools/wang-reference/excerpt_audit.py check
```

原頁正文仍只在本機忽略快取。`--source`會連人工核讀段及其跨頁續段；索引保存段號、原行及文字指紋，唔複製原書全文。
