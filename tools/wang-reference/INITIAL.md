# 初階講義：詳細摘要與查閱索引

今次先整理初階；深造索引獨立保留，唔作初階缺文嘅補寫來源。

## 怎樣用

1. 先按下面25篇導讀揀範圍；每篇有實際抽出嘅細節標題／星曜入口。
2. 用 `initial.py search` 查字詞／星曜／宮位／組合，再 `show --id` 連前後段讀。
3. 引用寫『初階轉錄・第N篇・小節・本次抽取段號』及原網址，唔把篇號／段號冒作原書頁碼。

```powershell
python tools/wang-reference/initial.py search --pair 紫破 --palace 交友
python tools/wang-reference/initial.py search --chapter 4 子時
python tools/wang-reference/initial.py show --chapter 21 --section 紫微
python tools/wang-reference/initial.py check
```

`--stars`包括明示小節星曜；`--pair`查段落或所屬分支明寫嘅組合名稱／簡稱，唔將兩星各自出現當同宮。
段落標籤只供查閱，唔係判斷層嘅已核條件；『若、但、唯、不』要連完整小節理解。

## 已知缺口與版本界線

- 25篇包括目錄，命身宮拆成兩篇；唔係25課，亦未能確認等於完整原書。
- 原書目錄列出『年限推斷法』及『後記』，呢組25個網址未提供對應獨立篇。第7、9、13、14及各宮篇已有部分運限方法，唔應因此話初階完全冇講運限。
- 第6篇安星簡表主要只有表名，未有相應圖像或HTML表格；其他篇亦多次提及圖一、圖二等而無相應圖片。不可據缺圖嘅例盤聲稱已核對完整命盤。
- 來源係署名王亭之嘅第三方轉錄；本次已讀取網頁同建立來源指紋，尚未對原書版本、原頁與作者定稿校勘。
- 第7篇四化口訣與同篇流月例子有庚干化科內部不一致；戊、壬表列值亦應保留來源版本，唔靜默改成專案採用表。
- 第11、12篇嘅差異獲第12篇後記明示，且後記另有本命與行運嘅閱讀前提。查基本星性時要連後記讀。
- 轉錄有疑字、缺句與年份疑點；已定位問題唔代表已改正，未核前保留待核標記。
- 內容摘要只描述講義觀點；書中歷史說法、作者自述統計、疾病及事件判斷，唔因有文本出處而成為現代實證或讀者已知事實。

**處理**：先記對象及各分支，三段並列核對；疑句未對原書，不定優先、不補主語。 狀態：`needs_original_collation`。
