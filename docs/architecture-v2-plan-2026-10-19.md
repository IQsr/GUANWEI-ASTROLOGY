# 新架構 plan：判斷層 + 寫作層（2026-10-19 草稿）

> 狀態：**草稿，未開工**。資料來源用 `tools/wang-reference/`（王亭之深造 595 頁 PDF + 初階 25 篇導讀）。

## 一、而家點解會自相矛盾

而家本書係咁砌出嚟：

1. **結論**：揀「領銜主星」嘅結論句。其後再用同宮整合版、帶條件版、骨架偏向，逐層覆蓋前一層。
2. **其餘幾格**（細讀、擾動、牽動、生活）：每粒星、每粒煞、每個四化各自攞自己嘅現成句。
3. **最後收尾**：`dropEchoes` 剷重複，`clash.ts` 搵相反講法，再剷句或者補「不過」。

問題在於：**冇一個步驟負責決定「呢個宮、呢個話題，最終講乜」**。每粒星都講自己嘅版本，事後再補救，只會出現以下幾種結果：

- 剷少咗，就照樣自相矛盾；
- 剷多咗，就留低冇主語嘅半句；
- 加「不過」，讀落又突兀。

大限、流年章亦係同一個毛病：佢哋抄返本命嘅句，冇講清楚同本命比較有乜唔同。

## 二、新架構

```
命盤（引擎，現有）
   │
   ▼
判斷層：條件卡 × 命盤 → 每宮每話題一個「判斷」
   │      （唔寫句子，只出結構化嘅結果，帶出處）
   ▼
寫作層：每個判斷講一次 → 結論、因為、留意、點做
   │
   ▼
大限／流年：同一套判斷再計一次，只寫同本命唔同嘅地方
```

### 2.1 條件卡（新資料，取代每粒星各自嘅句庫）

條件卡由索引入面嘅原文段落拆出嚟，格式擴展自 `deep/CONDITIONS.md` 嗰五張示範卡。下面用 C-001 做例子：

```jsonc
{
  "id": "card.jiaoyou.zipo.sha",
  "palace": "僕役",
  "topic": "受拖累",
  "subject": { "kind": "pair", "stars": ["紫微", "破軍"] },
  "when": { "all": ["見煞"], "none": [] },
  "stronger_when": ["見空劫"],
  "claim": "下屬或朋友會拖累你",
  "limit": "唔寫成所有合作都不利；武曲化忌、廉貞化忌另有分支",
  "sources": ["wtz.deep.p504.b010"],
  "layer": ["natal", "decade", "annual"]
}
```

每張卡有以下欄位：

- **`subject`**：分三種，組合（兩星同宮）、星系（六十星系）、單星。
- **`when` / `none`**：原文明寫嘅前提同排除條件。
- **`claim`**：用自己文字寫嘅原文重點，寫得唔可以比原文更強。
- **`sources`**：直接指去索引嘅段落 id。工具會檢查呢個 id 存在，而且原文指紋冇變過。

### 2.2 判斷層點揀

對每個宮，先定一張固定嘅話題表，每宮大約 3 至 5 個話題。例如僕役宮：助力、受拖累、交往深淺、合作持久。

每個話題按以下次序揀卡：

1. **條件唔成立嘅卡唔出。** 例如原文寫「見煞」，呢張盤冇煞，就唔出。
2. **組合 > 星系 > 單星。** 即係你之前定落嘅規則：「同宮兩星照組合讀」。
3. **帶條件 > 一般。** 條件越具體，優先級越高。
4. **原文本身有分歧時，唔准靠刪句解決。** 判斷入面記住「兩邊都有，條件係乜」，寫作層照講。
5. **冇卡命中，就寫少啲。** 寧願少講，都唔好用其他宮或者另一粒星嘅句頂上。

判斷嘅輸出形狀，現有 `schema.ts` 入面已經有 `Interpretation`：佢有 supporting、counter、mitigating 三組 id 同出處。呢個形狀當年已經設計好，只係一直冇資料去餵。我會沿用佢，唔另起一套。

### 2.3 寫作層

- **一個話題一段。** 順序固定：結論 → 因為（點出命中咗乜條件）→ 留意（修飾）→ 點做。
- **句子跟判斷走，唔再跟星走。** 呢樣係矛盾根治嘅地方：同一個話題只有一把聲。
- **en/ja 翻譯用卡 id 做 key，唔再逐句對中文。** 舊書照用舊 tm.json 渲染（R-008），所以舊 key 一律保留。

### 2.4 大限／流年

- **用同一套卡，套落大限盤、流年盤，再計一次判斷。** 卡入面要加時間層嘅條件，例如 C-004：流年通常先看大限同流年，生年四化被沖會時先另看。
- **只寫同本命判斷唔同嘅話題。** 每句都講明係邊層盤，例如「這十年的盤上」。
- **咁做之後，以下問題會一齊消失**：四化冇講係邊層盤、抄本命句、同一個化讀成兩樣。

### 工作量估計

- **卡嘅數量**：每宮大約 60 至 150 張，全書大約一千張上下。命宮最多：六十星系每個大約 8 至 12 張，合共大約五六百張。
- **點樣寫**：同上次標註一樣，用 sub-agent 分批寫。每個 agent 用 `deep.py search/show` 讀原頁，再寫卡。
- **點樣核對**：工具自動檢查出處 id。條件同語意由第二批 agent 對原頁覆核。分歧同疑字（`deep/REVIEW.md`）留畀你拍板。
