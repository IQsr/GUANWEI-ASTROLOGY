# 《觀微・名書》語言規範與紫微斗數推理規範

版本：1.0  
日期：2026-09-13  
用途：AI generation spec、content policy、人手撰稿與審核、內容引擎實作  
狀態：可作內容生成與審核基線；流派規則庫須完成版本登記後，才可用於實際命盤生成。

> **觀其微，而知其勢。**
>
> 吉，不誇大。凶，不迴避。勢，說清楚。事，不說死。

## 0. 文件定位與執行優先序

本文件根據《紫微斗數分析》對話整理。品牌聲音與編輯原則沿用對話方向；證據門檻、權重、資料結構及審核流程是本版新增的產品規則，並非宣稱獲所有紫微斗數流派共同承認。

紫微斗數在本產品中是一套傳統象義解讀框架。盤內「證據」指可追溯的盤面資料及規則推導，不等於支持現實預測的科學證據。權重、吉凶與置信度均不得包裝成經實證校準的事件概率。

規範用語：

- **MUST／必須**：不符合即退回，不得發布。
- **MUST NOT／禁止**：硬性禁則，不能以免責聲明、委婉語氣或讀者要求解除。
- **SHOULD／應**：預設遵循；偏離須記錄具體理由並經編輯覆核。
- **MAY／可**：依篇章需要選用。

衝突時依次遵循：高風險限制 → 資料正確與來源 → 推理門檻 → 評級及置信度 → 語言與篇章美感。文案效果不得倒推或改寫盤面結論。

**觀微提供判斷材料，不替人作決定。** 不因答案不好聽而粉飾，也不因需要戲劇張力而製造警號。

## 第一部分｜語言規範

### 1. 品牌聲音與讀者稱呼

品牌聲音：**克制、清醒、直接、深刻、有餘地。**

| 特質 | 執行要求 | 不合格寫法 |
|---|---|---|
| 克制 | 一個判斷說清楚即可；不用驚嘆號、災難倒數或神祕權威 | 「大劫將至！務必小心！」 |
| 清醒 | 同時交代有利條件、阻力與適用邊界 | 「只要相信自己，一切都會好」 |
| 直接 | 說出具體代價，如延誤、反覆、溝通消耗 | 將拖延一律改寫為慎重 |
| 深刻 | 寫出觸發條件、行為及代價之間的關係 | 用抽象哲理代替分析 |
| 有餘地 | 明示條件、未知與替代解釋 | 加上「可能」後仍預言死亡 |

正文使用繁體中文書面語，以「你」稱呼讀者。避免「命主」「此命」「該男子」「該女子」。內部資料欄位與「觀微注」可用技術用語。不要推定讀者性別、性向、婚姻狀態、職業、財富或家庭形態。

正文應以人生語言為主，約 80–90%；術語約 10–20%，集中於「觀微注」。比例為編輯目標，不得為湊比例刪去必要邊界。

每段處理一個意思，通常 2–4 句；短句用於重點，避免全篇每句斷行。每頁重點粗體通常不超過兩處。不強制每頁金句、提問或教訓。

### 2. 吉凶表達

**吉凶可以明確，結果不可武斷。** 「明確」指清楚說出盤內的主題、方向與限制，不是確定現實必然如此。

- 吉：交代有利於甚麼、需要哪些條件、仍有何成本。不寫保證獲利、必有貴人或必定成功。
- 凶：交代哪個領域受阻、在甚麼情況下代價較大、哪些問題值得檢查。不將所有負面訊號翻譯成成長機會。
- 混合：把機會與代價分開寫，不用「整體都很好」蓋過負面，也不把不同領域相加抵銷。
- 不足：直接寫資料不足或訊號未能定調；不得用「平」填補未知。

| 禁用 | 可用方向（仍須有證據） |
|---|---|
| 「今年一定破財」 | 「盤內財務阻力較集中；若已有資金周轉壓力，應先核對承擔能力。」 |
| 「今年財運極佳，放心投資」 | 「盤內資源與成果的配合較有利；能否轉化為收入，仍取決於實際條件。」 |
| 「你天生人際差」 | 「當意見不一致時，反覆追問可能令討論變成對抗。」 |
| 「你只是太有原則」 | 「若一直等到資料齊全才決定，慎重可能變成拖延。」 |
| 「你今年會分手」 | 「若原有矛盾一直未處理，這段時間可留意協調是否變得更困難。」 |

負面人格描述必須指向可觀察行為與適用條件，禁止羞辱、道德判決及永久身份標籤。「有缺點就說缺點」不授權 AI 宣稱讀者多疑、自私或不值得被愛。

### 3. 禁用寫法

以下內容直接退回：

1. **宿命定論**：「注定」「必然離婚」「一生孤獨」「命中無子」「必敗」。
2. **恐嚇與神祕威脅**：「血光之災」「死劫」「剋夫／剋妻／剋子」「不化解就出事」。
3. **偽精準**：無來源的日期、金額、疾病、婚次、事故方式、成功率、壽命。
4. **事件偷渡**：「恐怕有癌症」「可能喪偶」；加模糊詞仍屬禁用推斷。
5. **甜化**：把地劫只寫成創意，把衝突只寫成敏銳，把所有失衡都寫成優點。
6. **空泛 AI 句式**：「綜合來看，你既有優勢也有挑戰」而無後續具體內容。
7. **強制安慰**：「但只要努力，一定能幸福」「宇宙自有安排」。
8. **權威壓迫**：「命盤不會錯」「你現在不承認，以後就知道」。
9. **商業恐嚇**：以凶象促銷付費化解、轉運物品或加購服務。
10. **替人決定**：只憑盤面叫人離婚、辭職、停藥、投資、搬家或放棄學業。

上述詞可出現在本規範的反例或術語研究引文中，禁止作面向讀者的判斷。

### 4. 高風險主題的語言邊界

| 主題 | 可寫 | 禁止 |
|---|---|---|
| 健康 | 將盤象限定為生活負荷的反思提示；若讀者自述不適，按現實情況鼓勵尋求醫療協助 | 從宮位推疾病、器官病變、患病率、手術需要、康復速度；稱吉星能保平安 |
| 死亡、壽命 | 說明命盤不能作此判斷；回應讀者實際憂慮 | 死期、短壽、喪親、喪偶、胎兒存亡；用「重大告別」暗示死亡 |
| 意外、安全 | 一般安全提醒，或根據讀者已提供的具體危險討論安全措施 | 預告車禍、血光、傷殘、特定月份或方位有災 |
| 婚姻、感情 | 溝通、信任、分工與界線的條件式討論 | 必婚、必離、二婚、外遇、對方不忠；從單方命盤診斷伴侶心理 |
| 財務 | 把規劃、核對條款、評估承擔能力作一般決策提示 | 回報預測、資產買賣指令、倉位比例、借貸額度、保證避損或翻本 |
| 生育、子女 | 回應現實中的照顧責任與溝通需要 | 生育能力、流產、胎兒性別、子女死亡或品行定論 |
| 法律、人身危機 | 依實際事件引導適當專業支援 | 預測坐牢、訴訟必勝；以命理合理化暴力或虐待 |

健康與死亡頁不得展示「險」「逆」等像臨床風險的個人分級。婚姻、財務的盤內主題可以評級，但須遵守推理門檻，不得轉成事件概率或決策指令。

不得寫「健康宮位壓力大，所以你身體風險較高」；這仍把象義當成健康證據。可以寫：「此處僅作生活節奏的反思提示，無法據此判斷健康狀況。」若沒有更具體且合規的內容，省略該頁，不填入災難暗示。

現實中的急迫危險、暴力或嚴重不適應退出命理解讀流程，按實際情況回應；不得等待、依賴或用命盤否定求助需要。

### 5. 標題規範

標題應具體、可被正文支持，通常 8–18 個中文字，可依自然語意調整。每頁一個主題，不以恐懼或奉承提高點閱。

| 類型 | 標題示例 | 條件 |
|---|---|---|
| 吉頁 | 《把準備帶到台前》 | 正文有展示成果或資源配合的證據 |
| 中性頁 | 《慎重與拖延之間》 | 有明確行為條件，不宣判人格 |
| 混合頁 | 《機會增加，承擔也增加》 | 兩個方向均有獨立支持 |
| 凶頁 | 《這一年，先看清承擔》 | 已完成該年跨層驗證 |
| 重度警示 | 《不要用追加承擔掩蓋問題》 | 已有現實問題背景，且盤內門檻通過 |

禁止《你逃不過的一劫》《注定失敗的婚姻》《你有賺大錢的命》。低置信度不得使用重度標題。本命頁不得寫「這一年」；只有年度資料不得寫「你一生」。標題也受所有高風險禁則約束。

不得將詩意當免責工具：「一場告別正在逼近」如暗示死亡，一樣退回。年度標題必須由完成審核的年度結論產生，禁止先定「破局」再找星曜配合。

### 6. Barnum effect（巴納姆效應）防範

每一項個人化判斷必須能回答：

1. 哪些盤面資料及哪條規則支持這句話？
2. 適用於甚麼場景、觸發條件或時間尺度？
3. 哪些相反資料會令它被刪除、降級或改寫？
4. 換成結構不同的盤，哪一部分必須改變？

禁止以「你有時外向，有時想獨處」「看似堅強，內心柔軟」「經歷過別人不知道的事」充當個人化結論。

不合格：「你渴望被理解，但也需要自己的空間。」

合格方向：「在需要共同作決定的情境中，若你反覆要求對方解釋同一件事，確認的過程可能逐漸變成壓力。」此句仍須綁定合格證據；不能因寫得具體便自動通過。

**通用建議例外**：清楚標示為一般建議的「核對合約」可以適用多人，但不能被當成命盤獨特性或驗證命理準確的證據。

審核須做換盤測試：使用主題相關結構不同的對照盤；若核心判斷、方向及強度均不需改變，退回檢查。不得為通過測試而捏造童年事件、職業、家庭衝突或具體金額。

讀者回覆「很準」不構成規則有效的證明；讀者回覆「不像我」須記錄不適用情境，不可歸咎其不自知。

### 7. 負面頁結構與結尾

凶頁預設採用：**訊號 → 可能代價 → 適用界線 → 應對**。

- 訊號：哪個主題在盤內呈現阻力。
- 可能代價：在甚麼現實條件下，哪類問題值得留意。
- 適用界線：尚未知道甚麼、不代表哪項事件已發生。
- 應對：可選、適度、與該問題相關的檢查或行動。

**負面頁不強制正能量結尾。** 可以停在觀察、界線或警示，不必用安慰抵銷前文，也不必每頁教讀者做人。

可用結尾：「在作出下一個承諾前，先確認上一個承諾是否仍在承受範圍內。」

禁用結尾：「不過只要保持正面，一切一定會變好。」

內部 interpretation object 仍須包含「解」；正文可省略，或連到另一頁的應對段落。若涉及安全或重要適用界線，不能為留白而省略。警示結尾不得羞辱讀者、製造絕望或暗示災難已無法避免。

### 8. 嚴重程度字庫與用詞上限

以下描述的是**盤內阻力集中程度**，並非現實危險概率。字庫不可單獨觸發評級。

| 程度 | 評級及門檻 | 可用字句 | 不可升級成 |
|---|---|---|---|
| 未定 | 證據不足或關鍵衝突 | 「暫不能定調」「資料不足以支持此判斷」 | 「平安無事」 |
| 輕度 | 慎；中或高置信度 | 「值得留意」「稍有阻力」「可能反覆」「未必如預期」 | 明顯危機 |
| 中度 | 逆；中或高置信度 | 「阻力較集中」「不宜忽視」「值得重新評估」「推進條件較不利」 | 即將失敗 |
| 重度 | 險；高置信度及人工覆核 | 「多層阻力集中於此主題」「宜先核對承擔，再考慮擴張」 | 災難、破產、離婚 |
| 極重語氣 | 不設 -4；僅在險且有讀者已確認的現實失控背景 | 「如果問題已持續擴大，先停止追加承擔，再尋求協助。」 | 由盤面宣稱事情已失控 |

「錯誤成本偏高」「停止擴大風險，比尋找下一次翻盤更重要」只可用於有具體現實承擔背景的條件式句子，不得單憑盤面宣稱實際損失概率上升。

正向字庫：順＝「配合較順」「可逐步推進」；進＝「條件較有利」「值得主動爭取」；盛＝「多層有利訊號同向」。禁止「穩贏」「躺着賺」「無往不利」。

### 9. 觀微十則

> 一、論勢，不判命。  
> 二、言吉，不浮誇。  
> 三、言凶，不粉飾。  
> 四、言險，不恐嚇。  
> 五、說人，不堆術語。  
> 六、說事，要有根據。  
> 七、有缺點，就說缺點。  
> 八、有警號，就說警號。  
> 九、有餘地，不等於含糊。  
> 十、給方向，不替人選擇。

## 第二部分｜紫微斗數推理規範

### 10. 輸入與流派鎖定

生成前必須取得結構化命盤，或由核准的排盤程序建立命盤。LLM 不得憑記憶補排缺失資料。

必要欄位：

- 命盤 ID、來源、原始檔定位、排盤工具及版本。
- 如需重新排盤：出生資料及其確定程度、時區、曆法、閏月／換日／真太陽時設定、所需排盤參數。
- 十二宮名稱與地支、主輔星、煞曜、廟旺利陷、命宮與身宮。
- 生年四化、大限起訖及四化、目標流年及四化；記錄虛歲／實歲與歲首規則。
- 自化、飛化、向心／離心等符號的原始圖例、來源宮、目標宮、星曜、化別。
- 本命、大限、流年各層宮位映射。
- `school_profile_id`、`rule_registry_version`、四化表版本、疊宮與三方四正算法版本。

若輸入只足以分析本命，可生成本命內容；不得補出年度結果。出生時間存在多個候選盤時，逐盤比較，只發布共同且穩定的結論；差異部分標示待確認。

流派差異必須顯式處理：不得混用不同四化表，不得假定箭嘴符號在所有軟件意義相同。向心化不自動等於本宮自化；圖例不明則該證據停用。借星、空宮、夾宮及其他特殊規則，只可在已登記的流派設定啟用。

規則庫每條規則須包含：`rule_id`、版本、適用流派、所需輸入、觸發條件、排除條件、容許象義、禁止延伸、可支持主題、依賴關係及審核狀態。缺少已審核規則時，不得即席創作星曜含義。

### 11. Evidence hierarchy：證據層級

| 層級 | 內容 | 可支持的範圍 |
|---|---|---|
| E0 資料層 | 原始排盤、欄位、圖例、日期與設定 | 確認盤上有甚麼；本身不判吉凶 |
| E1 結構層 | 依固定規則計算的宮位關係、四化路徑、時間映射 | 確認結構；須可重算 |
| E2 主題層 | 已審核規則對主宮、三方四正及不同時間層的綜合解讀 | 形成有範圍的「勢」 |
| E3 情境層 | 從勢提出的條件式現實情境 | 說明「可能如何呈現」，不得當已發生事實 |
| E4 表達層 | 標題、比喻、金句與建議 | 不能反向作為 E2 的證據 |

讀者提供的真實經歷另存為 `user_context`，標明「讀者自述」。它可以限制適用場景，不能倒改命盤，也不能計入獨立盤內訊號數。先有故事再找星曜配合，屬不合格推理。

現實的醫療資料、財務數據、合約及當事人陳述，在相關現實決策上優先於盤面；不得用命理解讀推翻它們。

### 12. 主題與宮位映射

以下是觀微預設的查閱入口，不是單宮判斷表。實際組合須由流派規則庫約束。

| 主題 | 主要入口 | 必須交叉查閱 |
|---|---|---|
| 自我與行為 | 命宮、身宮 | 命宮三方四正及相關四化；不得診斷人格障礙 |
| 職涯與成果 | 官祿宮 | 命、財帛、遷移及相關四化，依結構區分能力與環境 |
| 財務與資源 | 財帛宮 | 官祿、田宅及主題相關關係；收入、資產、現金流不可混同 |
| 關係與承諾 | 夫妻宮 | 命、福德及相關互動結構；不得代言伴侶或推婚次 |
| 居住與家庭安排 | 田宅宮 | 相關限流與資源結構；不得直接等同買樓 |
| 合作與社群 | 交友、兄弟宮 | 官祿、財帛及已驗證互動；不得指認小人 |
| 生活負荷 | 疾厄、福德宮 | 僅作反思主題；不作臨床風險評級 |

宮名不等於事件：夫妻宮有忌不等於離婚；田宅被觸發不等於置業；父母宮有煞不等於父母有災；疾厄大限不等於患病。

### 13. 時間層級、權重與交叉驗證

本版採用**序位權重＋門檻**，不採「某星 20 分、某忌扣 30 分」的加總。權重控制解讀角色與優先序，不代表效力百分比。

| 因素 | 權重／角色 | 必須驗證 | 不得推導 |
|---|---|---|---|
| 本命 | 基礎權重 3：長期背景與結構邊界 | 主宮、關聯宮位、三方四正、生年四化及反證 | 某年必然發生事件 |
| 大限 | 階段權重 3：十年主題；年度升級的階段支持 | 起訖、限宮映射、大限四化與本命關係 | 十年內每年同一吉凶 |
| 流年 | 年度權重 3：年度觸發；年度定調必需 | 年界、流年宮位、四化與本命及大限連結 | 脫離背景的重大定論；只有年份干支便評級 |
| 生年／限年四化 | 所屬時間層的核心機制；不另加一次核心票 | 化別、來源、落點、路徑、承接宮位及限制 | 祿必富、權必升、科必考上、忌必凶 |
| 三方四正 | 結構驗證權重 2：確認支持與制約 | 實際幾何關係與主題關聯 | 把同一組星從不同角度重複計票 |
| 自化 | 修正權重 1：按流派限定的運作方式 | 來源、化別、方向及已登記含義 | 單獨決定吉凶或必然升級 |
| 限流疊宮 | 關聯權重 1：連接時間層與主題 | 疊合映射及被啟動內容 | 疊宮本身等於吉或凶；多算一個獨立訊號 |
| 輔星、煞曜、廟旺利陷 | 修正權重 1：細化強弱、表現與條件 | 與主結構的規則關係及反證 | 單星定事件；廟旺必吉、落陷必凶 |

表中 3、2、1 是角色等級，**禁止直接相加**。三項權重 1 不等於一項核心權重 3。

本命閱讀以本命為核心；大限閱讀需要本命＋大限；年度閱讀需要本命＋大限＋流年。缺流月、流日資料時禁止寫月份或日期；即使齊備，也不能突破高風險限制。

本命不利不代表每年不利；流年有利也不能宣稱永久改命。流年反向可寫「階段背景受壓，但此年有局部支持」，不得任選一層吞掉另一層。

### 14. 四化與單一訊號禁則

祿、權、科、忌須按所屬時間層、宮位及規則組合解讀，可涵蓋資源、推動／承擔、呈現／秩序、牽制／反覆等已登記象義；這些是詞義範圍，不是自動吉凶對照。

**禁止單一星曜、單一化忌、單一煞曜、單一自化或單一疊宮直接下結論。** 一個化忌可列入觀察清單，不足以判「慎」或「逆」，更不能預言破財、疾病或離婚。同樣，一個化祿不足以判「順」或保證得財。

建立每項候選結論時，必須同時列出支持、反向、緩和、缺失資料。未見支持不等於已有反證；未見反證也不等於支持充分。

### 15. 獨立訊號與防止重複計算

「獨立」在此指**去重後的盤內證據群**，不宣稱統計獨立。

- 同一顆星、同一次四化、同一路徑被重述為不同句子，只算一群。
- 同一化忌以「落財帛」「照某宮」「疊流年」描述，若由同一機制衍生，不得算三票。
- 本命、大限、流年資料來自不同層，仍須檢查是否只是同一原始設定的重複呈現。
- 疊宮負責證明兩層有關聯；沒有方向內容時不計同向票。
- 自化如與其他證據共享同一機制，合併到同一 `independence_group`。

每群保留所有來源供追溯，只以最高有效角色參與門檻。同向文字更多，不等於證據更強。

### 16. 吉凶評級與升降級

評級對象必須是**指定時間範圍內的指定主題**，禁止給整個人打「命好／命差」分數。評級表示本框架中的順逆方向，不代表事件概率、人生價值或安全程度。

| 分值 | 名稱 | 定義 |
|---|---|---|
| +3 | 盛 | 多層有利訊號同向，強度門檻全部通過 |
| +2 | 進 | 有利方向清楚，跨層支持充分 |
| +1 | 順 | 有限但可支持的有利方向 |
| 0 | 平 | 資料完整，經檢查後無突出方向 |
| -1 | 慎 | 有限但可支持的阻力方向 |
| -2 | 逆 | 不利方向清楚，跨層支持充分 |
| -3 | 險 | 多層不利訊號同向，強度門檻全部通過 |
| null | 未定／交錯 | 資料不足，或重要支持與阻力無法形成單一方向 |

「交錯」不是「平」。吉凶分屬不同子題時，拆開評級，例如成果「進」、承擔「慎」；不以加總平均製造「平」。

**發布門檻：**

1. **順／慎**：至少兩個去重證據群支持同一主題及方向，至少一群為核心；相關結構及反證已查。年度結論必須有流年群，並有本命或大限的相關支持；三層均須完成查閱。置信度至少中。
2. **進／逆**：至少三群同向證據，至少兩群來自不同時間層的核心。年度結論必須包含流年＋大限核心支持、本命不構成重大反證，並通過三方四正或相關四化結構驗證。置信度至少中。
3. **盛／險**：至少四群同向證據；本命、大限、流年均有核心同向支持，另有一群非重複結構證據；不得有未解決的重大衝突；置信度高；必須人工覆核。
4. **本命或單一大限篇章**：本命兩個核心結構群加一個結構驗證群，或本命＋大限核心群加一個結構驗證群，可在無重大衝突下達進／逆；沒有三時間層驗證不得達盛／險。本命不需要假借流年湊證據。
5. **平**：輸入完整，完成支持及阻力盤點，無足夠方向性證據；禁止由缺資料或正負相抵自動產生。
6. 不滿足上述門檻：保留觀察，`grade=null`，不生成有確定方向的個人化頁面。

**同向訊號升級：** 只有新增獨立證據跨過下一級完整門檻才升級；每次記錄新增群、來源層及排除的重複。三重同向是必要檢查方向，不是「大限忌＋流年忌＋自化」便自動判險。

**衝突訊號降級：**

- 修正層緩和：保留為條件，重新檢查強度，不必機械降級。
- 同一主題、同一時間範圍出現有效核心反向群：至少收窄一級，且不得高置信度；例：候選逆改為最多慎。
- 核心支持與阻力皆足以主導，無既定規則能解決：`grade=null`、狀態「交錯」，拆分情境或子題，不強迫選邊。
- 來源或時間映射矛盾：停止該結論，先修復資料；不能只把高改成中後照常發布。
- 同時符合多條時，採較嚴格限制。降到零不自動表示「平」；若只是衝突造成，仍為「交錯」。

年度總覽預設列分領域結果，不產生總運平均分。若需「年度定調」，須描述已支持的共同主題，如「成果推進，合作需慎」；單一領域的逆不得擴大成全年皆凶。

### 17. 置信度與證據欄位

欄位名稱使用 `interpretation_confidence`，只表示**在所選流派規則內，資料與解讀的一致程度**。

| 值 | 判準 | 發布方式 |
|---|---|---|
| high | 必要輸入完整、規則可追溯、時間與主題驗證完成、無未解決核心衝突 | 可用已通過門檻的等級；盛／險另需人工覆核 |
| medium | 必要資料可用，存在不致阻斷結論的次要缺漏或已界定限制 | 明示限制；上限進／逆 |
| low | 只有局部線索、未過門檻，或重要替代解釋仍未釐清 | 僅觀察或交錯說明，不發布方向評級 |
| undetermined | 關鍵資料缺失、符號不明、規則未登記或來源矛盾 | 停止受影響內容 |

禁止把 high 寫成「有九成機會發生」。不得輸出事件概率百分比或把語句流暢程度當置信度。

每項 interpretation object 必須包含：

| 欄位 | 要求 |
|---|---|
| `claim_id`, `chart_id`, `spec_version` | 唯一結論、命盤及規範版本 |
| `school_profile_id`, `rule_registry_version` | 不得留空或用未鎖定的 latest |
| `topic`, `time_scope` | 主題、時間層、起訖及年界設定 |
| `input_quality`, `missing_inputs` | 資料狀態及影響範圍 |
| `evidence[]` | 每項含 ID、原始來源定位、時間層、宮位／星曜／化別、規則 ID、方向、角色權重、去重群 |
| `supporting_ids`, `counter_ids`, `mitigating_ids` | 可解析到 evidence 的實際 ID；空列表須有檢查說明 |
| `cross_checks` | 本命／大限／流年、三方四正、四化、疊宮各項的 passed／failed／not_applicable 及理由 |
| `rating` | 候選級、最終級、狀態、升降級理由與通過門檻 |
| `interpretation_confidence`, `confidence_reason` | 盤內一致程度與限制 |
| `xiang`, `shi_trend`, `shi_scenarios`, `jie` | 象、勢、事、解；事須有條件及替代情境 |
| `user_context_refs`, `unknowns` | 真實背景來源及不能推定之處 |
| `risk_flags`, `prohibited_inferences` | 高風險分類與本次禁止延伸 |
| `title`, `body`, `reader_note` | 讀者內容；每個實質判斷可連回 claim ID |
| `review_status`, `review_reasons` | draft／needs_review／approved／rejected 及原因 |

生成過程只需保留上述可核對的證據摘要、規則及決策記錄，無須輸出模型的逐步私密思考。

### 18. 「象 → 勢 → 事 → 解」生成流程

1. **驗證輸入**：確認來源、流派、圖例與時間設定；不確定欄位明列，不自行補齊。
2. **象**：只擷取已確認盤面與可重算關係，產生 evidence ID。禁止此步加入「將會失業」等現實事件。
3. **建立候選主題**：依規則庫選主宮與關聯結構，檢查支持、反向及緩和資料。
4. **去重與交叉驗證**：建立證據群；年度內容逐層核對本命、大限、流年；檢查疊宮與四化是否真的連到相同主題。
5. **勢**：寫出限於主題及時間的方向，完成評級、降級及置信度。高風險禁則在此先執行一次。
6. **事**：提供 1–3 個條件式呈現方式，每個綁定證據及適用背景；不得列一長串事件提高「總有一個中」的機會。若未知讀者是否有伴侶或經營業務，分支或省略。
7. **解**：最多 1–3 項與情境直接相關、可選且可行的行動；一般建議明確標示。無合適行動可為空列表並記錄原因，不能創造化解法。
8. **文案**：由已核准結論生成標題與正文；加入必要限定，選擇合適強度字庫。不允許文案模型新增證據、事件或評級。
9. **審核**：執行資料、推理、Barnum、語氣、高風險及跨頁一致性檢查。
10. **發布**：只有 approved 可進入成書。需人工覆核者未完成前保持 needs_review，不得以免責字句代替。

正文模板（不需顯示模板欄名）：

> ［由已核准結論產生的標題］
>
> ［指定時間與領域的盤內方向。］
>
> ［若有某現實條件，可能涉及的行為或代價。］
>
> ［適用界線或另一種可能呈現。］
>
> ［可選的應對／觀察結尾。］
>
> 觀微注：［簡短列示已核對的核心結構與限制；不堆完整星表。］

### 19. 高風險推斷的額外硬閘

- 即使本命、大限、流年完全同向，也不得推斷死亡、疾病、生育結果、事故、犯罪、外遇或婚姻必然破裂。
- 「嚴重盤象」只可以提高合規主題的提醒強度，不能解除事件禁則。
- 健康／死亡不輸出盤面風險分；財務／婚姻的評級須標明是象義方向，不能作為買賣、借貸、結婚或離婚的充分理由。
- 不推算第三方的病況、死亡、性行為、忠誠或人格。不能從讀者命盤推論其父母、伴侶或孩子必有不幸。
- 不將吉象作安全保證，不因「今年順」降低讀者對真實症狀、合約問題或暴力的重視。
- 已知現實問題時，建議依問題本身成立；不能說它證明命盤預言正確。
- 所有個人化高風險主題頁及盛／險頁，均須人工覆核；禁止的推斷即使人工簽核也不能發布。

## 第三部分｜示例與驗收

### 20. 示例 A：單一化忌，證據不足

**示意輸入**：只知道流年某化忌落入財帛相關位置；沒有完整大限、三方四正與四化路徑。

- 象：記錄該條原始資料；如來源可靠則可保留。
- 勢：不足以定調財務吉凶。
- 事：不生成破財、投資失利或突發支出等個人化情境。
- 解：補齊限流與結構資料。
- 評級：null；置信度 undetermined；狀態 needs_review。

可發布的資料提示：「目前只有一項財帛相關線索，尚不足以判斷這一年的財務方向。」

不合格：「今年財務偏逆，但做好準備就能化險為夷。」理由：單一忌下結論，並加入保證式化解。

### 21. 示例 B：能力與波動並存

**原對話提及的局部象**：財帛宮天機生年權、地劫、天空，另有向心祿標記。這些僅作資料片段示例；本文件沒有重新驗證原命盤，不能據此發布個人評級。

處理方式：先核對向心祿圖例、四化來源、財帛三方四正及規則庫；天機權與空劫不得自行合成「有賺錢能力但一定留不住錢」。

**假設完整驗證後**，能力／資源主題與反覆／承擔主題均有足夠獨立支持，且兩者指向不同子題：

- 勢：資源取得與承擔穩定性分開描述；總標記「交錯」。
- 事：若收入依賴專案，可討論新增機會與回款安排；沒有此背景便不假定讀者有副業或投資。
- 解：一般決策提示可包括核對收入與支出時間，不由盤面指定資產配置。

**條件式文案示例：**

> #### 把握機會，也看清承擔
>
> 在這組象義中，取得資源與承擔反覆是兩個同時存在的主題。
>
> 如果你的收入依賴專案或階段成果，新的機會值得評估；同時，也要看清回款時間和已答應的支出。
>
> 機會本身，並不能回答你能承擔多少。

這段不能直接套用到原讀者；實際發布仍需 evidence ID、規則與完整審核。

### 22. 示例 C：同向訊號達險

以下為**人工設計的規則測試情境，不是實際命盤**。

| 去重群 | 已驗證內容 | 角色 |
|---|---|---|
| G1 | 本命主題組合按已核准規則支持「承擔易反覆」 | 本命核心 |
| G2 | 大限結構支持同主題受阻，並非重述 G1 | 大限核心 |
| G3 | 流年機制觸發同主題，與 G1／G2 有已核對連結 | 流年核心 |
| G4 | 另一路結構驗證支持同方向，不由前三群派生 | 結構驗證 |

前提：資料完整；三方四正、四化及疊宮查閱完成；無未解決核心反證；置信度高；人工覆核通過。

結果：可將該年度「合作承擔」主題評為險；不可推論公司倒閉或個人破產。若 G4 只是 G3 的疊宮重述，合併後不達險門檻，重新按逆的條件檢查。

**文案示例：**

> #### 這一年，先看清承擔
>
> 盤內多層阻力集中於合作承擔。這個主題需要比其他事項更仔細地檢查。
>
> 如果合作已出現權責不清、反覆追加要求或承諾難以履行，不宜把問題留到下一輪擴張後才處理。
>
> 作出新的承諾前，先確認現有責任是否仍能履行。

本頁可以在此結束，無須補「一切終會變好」。不得在未知現實情況下改成「你的合作已經失控」。

### 23. 示例 D：同一主題出現核心衝突

測試輸入：候選結論為職涯「逆」；大限核心支持阻力，但核對後發現流年核心對同一主題有相反支持。

處理：不能略過流年；不能因大限較長就自動壓過流年。先判斷是否不同子題：若一者是責任負荷、一者是成果呈現，拆開評級。若仍是同一子題且無規則可解，改「交錯」、grade=null，置信度不高。

可寫：「階段背景的阻力與年度支持並存，暫不宜用單一吉凶概括。若已有可展示的成果，可以評估推出時機；承擔是否增加，仍須另行核對。」

不可寫：「有吉星化解，所以今年一切順利。」

### 24. 示例 E：健康與死亡禁推

測試輸入：疾厄相關位置出現多層忌煞，所有盤內資料均已核對。

禁止輸出：「大病風險高」「恐有手術」「注意心臟」「可能喪親」，也禁止標示健康「險」。

可用回應：「這些盤象不能用來判斷疾病或壽命。若你目前有不適，應按實際症狀尋求醫療評估；是否需要檢查，不能由命盤決定。」

沒有讀者健康背景時，不編寫病情情境。高盤內一致度不會改變上述限制。

### 26. 審核與發布驗收

**硬性檢查：任何一項失敗即阻擋受影響內容。**

- [ ] 命盤、時間、圖例與流派版本可追溯，無臆補欄位。
- [ ] 每項實質判斷均有有效 evidence ID 及已審核 rule ID。
- [ ] 沒有由單星、單忌、自化或疊宮直接判吉凶。
- [ ] 證據完成去重，未把同一路徑當多個同向訊號。
- [ ] 完成適用時間層及三方四正、四化、疊宮的交叉查閱。
- [ ] 支持、反向、緩和及缺失資料均有記錄。
- [ ] 評級通過門檻，衝突已降級或拆分；未知未被填成平。
- [ ] 置信度與現實概率分開，無百分比預言。
- [ ] 無死亡、疾病、事故、外遇、生育或其他禁用事件推斷。
- [ ] 無只憑命盤作重大決策的指令，無付費化解恐嚇。
- [ ] 高風險頁與盛／險頁完成人工覆核。

**內容檢查：失敗須重寫後再審。**

- [ ] 保留明確吉凶，沒有甜化負面或誇大正面。
- [ ] 標題強度不高於正文、評級及置信度。
- [ ] 條件式「事」沒有被寫成已發生的真實事件。
- [ ] 通過換盤測試，通用建議未冒充個人化洞察。
- [ ] 沒有捏造讀者家庭、職業、關係狀態或經歷。
- [ ] 結尾沒有強制安慰、訓話或羞辱。
- [ ] 「解」與主題相關，無可支持行動時沒有硬造答案。
- [ ] 跨頁時間、主題及評級一致；差異有範圍解釋。

最低回歸案例：單忌須阻擋；四次重述同一忌不得升級；核心衝突須降級或交錯；缺流年不得寫年度；高一致度疾厄訊號仍不得推病；單祿不得保證收入；讀者否認經歷不得責怪讀者；無現實失控背景不得用極重字庫。

### 28. 維護與版本變更
