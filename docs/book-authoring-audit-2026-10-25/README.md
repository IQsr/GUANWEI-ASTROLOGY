## 兩個不同的星系編號

`local-profile-matrix.csv` 的編號是「該宮實坐主星組合及宮支」對應的六十星系；它不是出生盤命宮編號。`palace-matrix.csv` 的編號才是全張盤命宮所屬星系，然後逐宮記該宮實坐／借入結構。不能混用兩張表，亦不能把命宮某星系的性格句直接搬到夫妻、子女或父母宮。

## 借宮的合法範圍

六十星系各有正反宮支，實坐命宮共120種。現有主星幾何只有12類組合可以被借入空命宮，正反共24種；其餘48類的「命宮借入」是幾何上不適用，並非欠48份稿。其他十一宮仍須逐張盤另判有無主星。本批144張結構盤生成的1728條宮位記錄，包含288條借宮，並不是只有24條借宮。

## 欄位及觀察碼

- `registeredRuleIds`：依主星組合找到的候選；不代表完整前提已成立。
- `matchedRuleIds`：按現行普通宮位predicate核對成立；借宮原閱讀器不執行個人分支，留空不能當成「確認無作用」。
- `selectedRuleIds`：原閱讀器真正選中的規則，未包括命宮專用分支、殘段context及跨宮新稿；不能用零值直接判為無個人分析。
- `crossFamily` 是已登記家族；`crossParagraphs` 是真正在這張盤、這章選中的段數。家族存在不等於所有樣本均符合其窄前提。
- `adviceMode` 由現有ID及選取流程反查，是審閱線索；目前產品沒有完整的建議→章節重點關係紀錄。
- `referenceCharacters` 只量編輯參照說明，不含原文全文；不是「據」的總長度，更不是語意正確率。
- `E-QUERY`：普通閱讀器仍用P0目錄，新增P1資料由另一分析路徑使用。它不是某一顆未用星必須寫入的證據。
- `E-BORROW`：借宮仍以主題參照為主，進一步分支需另立有來源關係。
- `E-CROSS-COVERAGE`：該家族沒有專用連讀；`E-CROSS-GATE`：已有家族但本盤未選中，原因可能是必要前提不符，不能一律修成選中。
- `W-DEPTH-REVIEW`：沒有普通個人修飾或跨宮段的候選；可能已有足夠主題，也可能有殘段context，必須人工核讀才可裁定薄弱。
- `A-TRACE`、`R-CLAIM`：建議承接及逐主張引用的共用資料結構尚未齊備；不是每段已確認離題或錯引。
