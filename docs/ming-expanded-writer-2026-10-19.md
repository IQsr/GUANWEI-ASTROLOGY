# 命宮展開寫作層

`writeMing(chart)` 現在預設輸出展開版。`assembleAll(chart, byTopic, { seed, mingWriter: 'cards' })` 同樣採用展開版，只替換命宮；其餘十一宮及預設 `legacy` 路徑不變。網站尚未切換。

## 閱讀結構

每個有已核內容的話題先給結論及解釋，再以明確標示的情境例子、編輯建議幫讀者理解；盤面依據放全章最後。沒有新的依據便省略，不用泛泛後備句。可獨立成立的提醒以提醒段落呈現，不冒充結論。組裝成 `Chapter.text` 後保留段落分隔。

逐句 `kind` 分開 `interpretation`、`editorial-explanation`、`editorial-example`、`editorial-advice` 及 `evidence`。解讀保留卡 ID 與來源段落；例子及建議只記依據卡 ID，不掛原書引文。例子並非斷言讀者曾經發生該事件。

## 已核範圍與留白

本次核讀《深造講義》六十星系相關原段及前後文，重寫六十條本命核心解讀，另准入十一條本命分支，共七十一條。各星系有獨立的結論與解釋；情境及建議按七類主題選取並在章內去重。

這並非把全部舊卡標成已核。原卡庫的 draft／needs_atom／hold 狀態保持原樣；展開版另用 `cards/ming-reviewed.json` 記錄逐項准入。未核的格局、處事、待人、運程不補寫，所以其他命盤也有展開結構，但不保證每盤同樣篇幅或五個話題齊全。八張實際稿中，三張原比較盤約八百至一千一百中文字，其餘五張約三百字，反映已核內容的多寡。

未核的性質點票、貪狼子宮天刑富局、欲望淡，以及相關大限改觀，均不由展開版輸出。運限尚未逐項准入，所以 `mingDecade`／`mingYear`／`mingFlow` 的預設展開路徑留白。即使整章沒有可用內容，也不退回未核舊章。

`{ style: 'compact' }`（組裝器為 `mingStyle: 'compact'`）保留原短版供診斷及回歸測試，並不代表其中判斷已獲准入。

## 後續准入程序

1. 先按 `tools/wang-reference/README.md`、`DEEP.md` 的入口查組合／宮位，讀原段及前後文，核對四化、配曜、廟陷與本命／運限層次。
2. 分別判定定位、字詞、條件及語意是否支持；必要、否定、例外與時間條件必須保留。不能只因掛有出處就視為已核。
3. 收窄或改寫消費句，寫獨立解釋，區分編輯例子／建議。無法核實的部分繼續省略。
4. 完成語意核讀後才更新准入 key 與來源 hash，記錄核讀決定並跑測試。key/hash 是防止舊裁定套到變動資料的護欄，不能代替核讀。

准入 key 包括中英文句子、限制、適用條件及來源；學派設定亦須相符。測試再鎖定來源段落、條件引擎及星系輸入指紋。任何變動都須重核，不應只重新計算指紋使檢查通過。
