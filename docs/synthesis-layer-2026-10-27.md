## 3. 新架構：四步

```
盤 ──► ① 因素表 ──► ② 判斷卡配對 ──► ③ 裁決 ──► ④ 寫作
```

### ① 因素表（每章一張，純計算）

由引擎資料砌出，章節之間共用。一宮嘅因素：

| 欄 | 內容 | 例（2004 女 夫妻宮） |
|---|---|---|
| 主星 | 實坐，或借星（記錄借自邊宮） | 空宮，借丑太陽、太陰 |
| 廟陷 | **按王亭之 p.327 表** | 太陽丑：陷（現表誤作「不」） |
| 四化 | 分本命／大限／流年，記錄落邊粒星 | 本命太陽化忌（在丑） |
| 同度 | 本宮其他星 | 天鉞 |
| 會照 | 三方四正，分「本宮」同「借入宮」 | 丑：天魁、陀羅；亥：左輔、空劫；卯：右弼、擎羊 |
| 夾 | 左右兩宮 | … |
| 讀者 | 性別、日夜生、虛歲、年齡段 | 女，夜生，23 |

因素表亦係 lint 嘅基礎：任何句子點名一個因素，因素表冇，就係錯。

### ② 判斷卡

沿用 `card.ts` 嘅格式，推廣到所有宮同運限，加以下欄位：

| 欄 | 用途 |
|---|---|
| `quote` + `source`（段 id、頁、指紋） | 原文斷語，逐字。寫作時引用，評審可以查 |
| `when` / `none` | 原文明寫嘅前提同排除（現有） |
| `seat` | `seated`（只限實坐）／`borrowed`／`both`。**預設 `seated`** |
| `layer` | `natal` / `decade` / `annual`（現有）。本命卡唔可以由流年四化觸發 |
| `specificity` | `general`（例如 p.236 化祿通則）／`system`（星系專條，例如 p.446 卯酉天同化祿） |
| `group` | 同一個因素嘅卡歸一組，用嚟做 §③ 嘅專條優先同覆蓋檢查 |
| `polarity` | `吉` / `凶` / `中` |
| `weight` | `斷`（原文用「主」「決主」「必」）／`傾`（「往往」「易」「多」）／`提`（「樞紐」「可視為」「宜」） |
| `advice` | 可選。只可以係由呢張卡推出嘅做法，並寫明點解 |

### ③ 裁決（規則，唔係 AI 判斷）

每章揀 1–3 個判斷：

1. **專條優先**：同一 `group` 入面，`system` 卡有命中就壓過 `general` 卡；`system` 卡存在但唔命中，`general` 卡只可以出「傾向」級（見 §5）。
2. **吉凶並見**：同一話題同時命中吉卡同凶卡，就唔揀一邊，寫一句「兩面」判斷。格式固定為「X 令你…；但 Y 令你…」，兩邊都要點名因素。呢個唔係兜圈：兩邊都係講你嘅具體判斷。
3. **偏向**（穩重／浮薄、上進／下游之類）：只用原文明寫嘅判準。原文冇權重就**唔點票**，改為列出兩邊因素，強度最多去到「傾向」。
4. **最高級**（最、一生最、最順）：只可以由比較函數產生，即係所有大限或所有宮都計過一次再排。單張卡唔可以自己講「最」。
5. **缺乏唔等於相反**：「沒有某條件」只會令某張卡唔出，唔可以推出相反嘅判斷（例如「天同冇化忌」唔等於「嗰年一定好」）。

### ④ 寫作

- 一章 = 1–3 個判斷。每個判斷：結論句（用「你」）→「因為」（點名因素）→ 原文引句同頁碼。
- 建議只可以來自卡嘅 `advice`。冇就唔寫，唔再用模板尾句。
- 全書改為按問題分章（§3.1）；書頭一段「你張盤最突出嘅三樣」，由比較函數揀出最具體、最少見嘅命中（例如「白手興家、晚年先順」）。
- 「給你的話」改為跨章合讀，唔再抄結論。
- 時運章由運限卡產生。王亭之喺好多星系篇都逐個列出運限（例如 p.130–131 天機丑未、p.192–193 機巨卯酉），呢批係最有價值嘅材料，要優先入卡。

## 5. 推論強度控制

每個判斷都有一個強度，由「卡嘅 `weight`」同「條件命中程度」一齊決定：

| 強度 | 幾時用 | 寫法 | 例 |
|---|---|---|---|
| **定論** | 卡係「斷」，條件全部命中，冇凶／吉卡相反 | 「你…」「你的錢…」 | 你的錢是自己一手一腳掙回來的。 |
| **傾向** | 卡係「傾」；或者條件部分命中；或者吉凶並見；或者只有通則冇專條 | 「你較容易…」「…的機會較大」 | 你較容易在順境時想搏大。 |
| **提示** | 卡係「提」（樞紐、宜）；或者只係年份、時機 | 「值得留意…」「…前後可以多看一眼」 | 二〇三一年前後值得預早準備。 |

- 降級只可以向下：條件差一項，定論變傾向，唔准升級。
- 重話（生離死別、重大災難、官非）照寫，但一律最高「傾向」級，並且一定要寫明觸發條件（用戶決定，§8 第 2 項）。
- 強度寫入每個判斷嘅資料，「據」面板顯示。lint 按強度檢查用詞（例如提示級唔准出現「必」「主」）。
