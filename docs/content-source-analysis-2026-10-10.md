# 中文命書：原典對照與內容深化試做

日期：2026-10-10。範圍：四組現有句子；研究及候選文案，尚未修改產品內容。

## 結論

可以用原典增加命書深度，而且材料比目前單星基塊豐富。但這次發現，真正要補的是「原文如何支持這個主張」，不只是新增來源名稱。

現有部分基塊的引文存在、星宮也對，正文卻另寫了一種心理行為。引文吻合不能證明語意推導吻合。四組試做中，有的可找到更細的組合與條件，有的只能收窄或刪除，不能全部靠補一句引文解決。

以下的「支持」只指傳統文本內的支持，不代表已由真人資料驗證。不同書可能沿用相同傳統，不能按「兩本書都提到」當作兩份獨立實證。

## 本次怎樣讀

- 以使用者提供的初階筆記作目錄線索；筆記本身明說是摘要，沒有把它當作原書逐字依據，也沒有核對其所有外部網頁。
- 提取四份 PDF 的文字，查相關段落，再渲染並查看相關原頁。深造講義有 595 頁；全書卷一、二、三的 PDF 分別有 20、32、15 頁。本次是定向查閱，沒有逐頁審完全部內容。
- 深造講義的頁碼按本次 PDF 的一基頁序，選取頁亦可在頁底看到相同頁碼。《全書》的頁碼是這次網頁列印 PDF 的頁序，不能換作古本頁碼。
- 重新排目前示範生辰及第二個既有測試生辰，核對規則前提；沒有改四化、廟旺表或排盤設定。原書與現行廟旺表的差異仍按專案既有決定保留，不能默默混用。

## 一、命宮：天同天梁、天同化忌

### 現有文字

示範命宮先說日子舒服、福氣厚、不必替它擔心，後面又說化忌使舒服條件最缺。這一章把一般星性、廟旺修飾及四化各自寫成完整斷語，讀者看不到它們如何互相修正。

### 原文提供了甚麼

| 位置 | 可提煉的文本觀點 | 必須保留的界線 |
|---|---|---|
| 《全書》卷一 PDF p.7〈問天同星所主若何〉 | 溫和、享受與福的基本象義 | 同頁亦有吉曜、煞曜、坐落等條件，不能只取一個「福」字 |
| 深造 p.14〈天同〉 | 作者把天同之福解作經挫折後的安定與享受，不是自天而降 | 不可轉為對讀者未來必先苦後甜的事件保證 |
| 深造 p.16〈天同〉 | 同梁與天馬、火鈴等配合會改變基本性質；吉化、祿存亦需參看 | 同一頁的平穩與受阻條件不能分開各自當最終結論 |
| 深造 p.87–88〈17 天同天梁坐寅申〉 | 分浪漫、原則兩面，也承認調和；火鈴等推向原則，但化忌且羊陀夾忌另有較差的組合判讀 | 不能只因火星便把整個人定成原則穩當；原書的羞辱性性格評判不沿用 |
| 深造 p.309〈天同（庚干化忌）〉 | 寅申同梁化忌需參看祿存；無火鈴空劫與有煞的分支不同，牽涉耗神、變動與安定 | 分支不能跨宮移用；不沿用同章疾病及財務事件預言 |

### 示範盤實際條件

命宮申：天同化忌、天梁、火星、祿存、天馬。前宮未有陀羅，後宮酉有擎羊，故羊陀夾住此命宮。

這比「天同旺，所以舒服」複雜得多。原文至少要求一起檢查：同梁兩面、化忌、羊陀夾、火星、祿存及天馬。這些訊號有不同作用，不宜靠逐段相加或單純吉凶抵銷定調。本次也沒有為它們另造量化權重。

### 候選正文

> 你重視日子的安定，也有自己想守住的原則。這張盤同時有偏向原則的訊號，以及令天同天梁兩面較難調和的組合，所以不宜只用「和緩、舒服」概括。值得核對的是：當享受生活與守住原則不能同時做到，你怎樣找出自己接受的取捨？

第一句依基本星性與同梁組合重述；第二句依本盤條件收斂判斷；最後是編輯設計的反思問題，不是原書已證實的讀者行為。此稿仍需與其他章及組合覆核，不能直接替換所有天同章。

**內容增加的地方：** 由星名清單走到真實的組合拉扯，並交代為何不能用一個舒服的結論概括。原先的表面矛盾有機會用原文解開，但不能擅自補成「外在舒服、內在辛苦」，因為還須有對應證據。

## 二、官祿：天機

### 現有文字與所掛來源

目前基塊說天機擅長拆解、變通，重複工作會失去耐性；所掛 cell 引文是《全書》卷二官祿段的古代地位描述。這個引用不能單獨支持「你會厭倦重複工作」的心理機制。

### 原典比較

- 《全書》卷一 PDF p.6〈問天機所主如何〉確實有機變、謀略的基本象義，所以「變通」並非完全沒有傳統根據。但一般星性不能自動支持某一宮、某一工作情境的全部描述。
- 《全書》卷二 PDF p.29〈九官祿〉主要談廟陷、配星與功名地位，沒有直接說固定工作令天機失去耐性。
- 深造 p.522〈事業宮・天機〉談事業變動性，並分化禄、化權、化科、化忌。計劃／管理／設計在這裡有化科等條件；不能拿走條件改成所有天機都適合。
- 深造 p.523 補充昌曲、天才等同度條件，又分子午獨坐與丑未等宮位。子午天機還有費心經營、開創方面的限制。這些比單一句「善於變通」更適合增加深度。

示範官祿是天機獨坐子宮，該宮沒有同坐昌曲、天才，天機亦沒有生年化科。現有文字中的「顧問、策劃」不能只依一般天機而選；顧問的明確組合材料另見 p.524 的機梁分支，不能套到此盤獨坐天機。

### 可以保留及應收窄

| 主張 | 判斷 |
|---|---|
| 一般天機有機變、謀略象義 | 有原文支持，但只在一般星性範圍內 |
| 天機守事業，需留意工作的變動性 | 有該宮材料；仍须按星系、四化修正 |
| 所有天機都擅長設計、適合顧問 | 條件不足；不能通用 |
| 因天機所以厭倦重複、失去耐性 | 本次相關段落未找到直接支持；宜移出個人化核心判斷 |

### 候選正文

> 工作上，這一宮較值得留意的是變化，以及變化背後需要付出的心力。你的官祿宮天機獨坐子宮；依這套讀法，不能只把變動當作長處，也要核對工作是否一直需要你費心經營。你可以回看：過去的改變，是帶來了更合適的工作，還是令你不停重新適應？

這是按已核對材料收窄的候選稿，末句是邀請核對，沒有宣稱讀者一定轉工。若另加任務、客戶、兼職等生活例子，必須標示示例並核對來源分支，不能當作已知經歷。

## 三、父母：天機巨門

### 現有兩種相反心理描述

目前天機塊說不正面爭、繞路辦事、分歧不攤開；巨門塊說追問為甚麼、分歧攤在檯面。第二本的結論及生活段只選天機，正文卻加入巨門，所以衝突留給讀者自行解決。

### 原文查到的是另一類材料

- 《全書》卷二 PDF p.32〈父母〉的天機段談廟陷、配星及父母關係的古代結果；沒有直接推出「绕過爭辯」的行為。
- 深造 p.583–584〈父母宮・天機〉主要談兩代距離、關係及條件變化；卯酉機巨另有專門段落。
- 深造 p.592〈父母宮・巨門〉重新解釋部分古代親屬斷語，區分不同程度與寄宿、寄養、照顧等情況。仍不是「你一定會追問規則」的溝通風格描述。

第二個測試盤父母宮在卯：天機化權、巨門、地劫。原文的一般天機、卯酉機巨，以及化權和空劫等細節不能各取一句就合成一個確定心理人格。

**這次不能靠補原文修好原有的心理故事。** 對已查段落，未找到足以支持「你繞過分歧」或「你把分歧公開」的直接描述；不能用巨門的一般口舌象義反推出你必然怎樣面對父母或制度。

### 保守候選正文

> 這一章可以先核對你與長輩之間的距離。相處時間少、生活安排不同，和彼此難以理解，是不同的情況，不能只憑這組星認定原因。若你感到有隔膜，可以從實際來往與共同決定的經驗開始；若沒有，這一段便不適用。

其中距離的觀察方向取自本宮材料，情境區分及核對方法是一般編輯提示；沒有把它們冒充為原典的個人化推論。這稿刻意較收斂。要把此章寫得更個人化，需要更直接的關係／行為材料或讀者提供的情境，不能為增加篇幅而添故事。

## 四、子女：廉貞、廉貞貪狼

### 現有文字

基塊把廉貞寫成投入極深、要求到位、原則整套交給後輩或作品；其《全書》來源卻主要是古代子女數目及親屬結果。生活句另由中州材料轉寫「最後也能互相體諒」。兩者的來源質素不能一概當相同。

### 原文差異

- 《全書》卷二子女段（PDF p.25–26）不能單独支持上述培養心理機制；本次沒有把子女數目、不祥親屬斷語翻成「高標準」。
- 深造 p.417 明說廉貞在子女的一般情形偏向兩代感情濃厚、隔膜仍可互諒；緊接著提醒四化及具體組合可改變細節。正文拿走一般性質的範圍，再加「最後」，便變成和解保證。
- 深造 p.418 在部分具體分支明說可對晚輩同推。這可支持特定分支的晚輩範圍，不能因此把所有子女宮規則再推成對作品、學生、下屬都一樣。
- 深造 p.419 有巳亥廉貞貪狼分支，吉化、化忌及配曜條件另論。不能只保留 p.417 一般吉句，忽略組合細節。

示範盤子女宮巳：廉貞、貪狼、左輔，廉貞沒有生年化禄／化忌。本次也不因沒有那兩化便宣布感情必定融洽。

### 可以如何改

可將「最後也能互相體諒」收為「一般性質保留互相理解的可能」，再按廉貪及相關配曜決定是否能對本盤定向。不把孩子／後輩的品格、未來結果或是否和解寫死。

至於「對自己的作品投入極深、降低期待比降低標準更難」等句，本次核對的本宮來源不足以支持；宜標為待核，找到明確材料前移出核心斷語。文句好讀與有原文根據是兩種驗收。

## 建議採用的來源分層

| 層次 | 保存甚麼 | 可以如何入正文 |
|---|---|---|
| 直接材料 | 書、章、PDF頁、短引文、前後文 | 原書確實說到的性質或關係 |
| 有條件材料 | 星系、宮支、廟陷、同度／會照／夾宮、四化、時間層，以及例外 | 條件全部核對後，才用於該盤；不能拿走前提 |
| 編輯例子／一般建議 | 如何把材料講清楚、核對問題、示例場景 | 清楚是提示或示例，不新增命盤已知事實 |
| 待核主張 | 引文存在但不支持該意思，或範圍、強度超出來源 | 暫不作個人化核心結論 |

每一項核心判斷都應有來源鏈，而非只求大部分段落有一個引用。純粹閱讀說明及一般提示可另列，不必把它們偽装成命理規則，也不宜設定一個沒有依據的「引用率達標」百分比。

最低資料應包括：**主張、來源定位、原文條件、本盤條件是否吻合、反證／修飾、時間與主題範圍、轉寫版本、編輯增加了甚麼。**

## 可以實行的內容流程

1. 先按星系、宮位及時間層找材料，讀完整相關段落，不能只搜一句好聽的句子。
2. 把原文拆成可核對主張和條件。先判定支持到哪裡，再寫文案。
3. 同一個人的相反材料放在一起處理。能由原書分情境才分，無法解決便保留交錯。
4. 文案完成後反向逐句查：哪些是文本支持、哪些是編輯示例，是否新增了人格、經歷或結果。
5. 用有／無修飾條件的對照盤檢查，確保關鍵條件改變，結論也會改變。引文存在測試與語意覆核要分開。

優先改造天同天梁命宮及天機官祿，因為本次已找到較豐富且貼近的材料。天機巨門父母與廉貞子女則先整理支持範圍，再考慮擴寫。原書中的疾病、死亡、子女數目、羞辱性人格判決及保證事件，不因有出處便自動成為產品可用內容。
