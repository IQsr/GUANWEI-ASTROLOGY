# 跨宮正式成書接入與五盤收結修正

日期：2026-10-25。基線：main `182d904`。本機分支：`codex/cross-palace-production`。未 commit、push 或部署。

## 原因

跨宮稿最初按本機預覽實作，`bookChapters` 的 `crossPalaceReading` 預設不開啟；只有預覽三組傳入 true。之後程式合併，但 `castChart` 與 `sampleBook` 沒有改接入。這是呼叫端遺漏，不是 Vercel 版本或 CI 問題。

另一個獨立問題是收結在章節套用新稿之前，已由 `epilogueChapter` 使用舊星系偏向及 plain 摘要生成；因此正文保留分歧，收結卻可能直接肯定人格、職業及財富。

## 本次實作

- 新增統一的新書入口 `createBookChapters`。正式排盤 action、公開示範書及本機預覽均由此進入，提供明確出生性別，啟用既有跨宮條件選稿。
- `bookChapters` 保留作基線生成器及歷史回歸比較；不刷新 75 本完整舊書雜湊，也不改寫舊書。正式入口整合測試實際呼叫 `castChart`、保存 draft，防止只測到新 helper 而漏接 action。
- 仍須完整通過既有規則、宮序、借宮、實坐、四化及前置條件；不符合時保留已核原稿。既有跨宮深入稿仍只覆蓋已核的同梁、天府、機梁三族，沒有宣稱已擴充至其他星系。
- 目次原只認命宮「展開」段；加入對已保存、帶跨宮來源的「細讀」段支援，恢復目次繁簡來源及英日原版譯稿，不讀取付費章正文。
- 新收結在最終選稿之後生成，不再抽用舊的強弱點票及 plain 個人標籤。
- 五盤所屬的廉破卯酉、七殺子午、天同卯酉、紫府寅申、武破巳亥，新增兩段編輯連讀撮要；先確認實坐結構，再承接命宮、官祿、財帛、福德的原有來源及完整條件。它們是正文的編輯綜合，不是新增命理分支。
- 其他星系先使用完整已選正文段落，保留否定及已確認修飾，避免未經核讀的自動縮句。
- 紫府收結不再直接列為攻守兼備；廉破命宮建議回扣角色與職責，天同命宮建議回扣精神寄託；七殺官祿重複的輔弼／魁鉞段合併，兩段的引用、條件及例外全部保留。
- 每個有來源段落仍只有一個「據」；收結先列本盤範圍和直接支持原段，再列完整條件與前後文。來源文字、PDF頁序、疑字、否定及例外不改。

## 保存及讀回

新書版本增加 `cross-palace-production-v1`、`epilogue-reader-v1`。繁簡收結保存自己的逐段正文、來源及條件快照；英日仍保存同一成書時刻的原版，不由新中文猜譯。

讀取端只對帶收結版本的新章取 `chapter_reading`，而且必須先經 `chapter_body` 的所有權及購買檢查。未改 SQL schema、RPC 或權限；本機 PGlite 實測新快照儲存／讀回、未購買、其他讀者及重送不覆寫。沒有連線更改線上資料或舊書。
