## 一、大原則

| | 建議 | 其他選擇 | 理由 |
|---|---|---|---|
| ✅ 術語寫法 | 日本坊間慣用 + 新字體：紫微斗数、化禄、官禄宮、福徳宮 | 照繁體原字 | Issac 定 |
| ❓ 文體 | 正文用**です・ます**；標題、印、落款用體言止め | だ・である | 日本占い書、星占い多數用です・ます，讀落似同讀者講嘢；である會似教科書。審稿人覺得太軟可以轉 |
| ❓ 第二人稱 | **あなた**，但能省就省（日文唔使句句有主語） | 君／貴方 | 中文「你」每句都有，照譯會好重複 —— 試做命宮已經刪咗大半 |
| ❓ 星名讀音 | 正文淨寫漢字；註層第一次出現加ふりがな（天同〈てんどう〉） | 正文都加 | 日本讀者識字唔一定識讀；ふりがな喺 `<ruby>` 做，唔入翻譯表 |
| ❓ 年齡 | **数え年**照寫，第一次出現註「数え年（満年齢＋1〜2）」 | 換滿年齡 | 日本紫微斗数本身用数え年計大限；英文先要換實歲 |
| ❓ 時辰 | 「子の刻」；括號寫時刻（23〜1時） | 子時 | 日本講時辰慣用「〜の刻」；早子時／夜子時照寫（早子の刻／夜子の刻） |
| ✅ 曆 | 西暦 | 新暦 | 落款嘅「國曆」 |
