# 綜合判讀層上線計劃（2026-10-28）

## 而家點運作

- 開關：`createBookChapters(chart, { …, synthesis: true })`（`apps/web/src/lib/mingshu.ts` `withSynthesis`）。成個 web 冇一處傳 `true`，所以讀者見唔到。
- 開咗之後，只換兩章：財帛章 →「錢」、這一年 →「今年」。卡冇命中嘅盤照用舊章。
- 書成書嗰刻存入 DB（`cast/actions.ts` → `keepBook`），之後唔會變。所以開關只影響**新書**；已經存咗嘅書照舊。
- 英文、日文：新章帶住舊章快照（`international` / `internationalSnapshot`），`internationalMing` 對 `synthesis-v1` 回 null，英日就照舊譯舊章。已試三個盤：英日正文同關開關時一模一樣，冇報錯。
- 中文頁讀得到新章（`readingOf` 接受 `synthesis-v1`）。

## 開之前要修

**1–3 已修（2026-10-28）**：章名照舊（財帛章冇 title、由 `chapterDrafts` 按次序編號；改名會令財帛冇號、後面宮位章全部錯號，英日亦冇譯名），只換正文；通則版 1 個判斷 + 最少 1 個宮段就成章，300 盤冇今年章 21 → 0。`apps/web/test/synthesis-switch.test.ts` 鎖住：開關前後章名同編號一樣、英日正文一樣、中文讀到新章。


1. **英日章名**：開咗之後章名變「錢」「今年」，英文、日文冇對應譯名，目錄會直接出中文「錢」「今年」，但內文係舊章。改法：英日顯示舊章名（財帛章本身冇 `title`，由 slug 砌；「這一年」→ This Year），即係 `withSynthesis` 只改中文章名，或者英日讀快照嘅章名。
2. **中文章名同目錄**：財帛章原本冇 `title`（目錄由 slug 砌編號），換成「錢」後要睇目錄、章首、上下章連結係咪仍然正常（要開 preview 實睇）。
3. **年長讀者冇今年章**：300 盤有 21 個冇（全部 1951–1971 年生）。原因：文昌化科兩張卡限虛歲 <56，年長讀者通常只剩「化忌落點」一張通則卡，夠唔到兩個判斷。改法：通則版只要 1 個判斷 + 最少 1 個宮段就成章（宮段本身係流年宮判斷）。
4. **再盲評一次**：ab9 之後改咗兩輪（`opposed()` 兩邊化、底子禁字、`concrete()`、話題名），未驗證。五盤，新章對舊章（唔係新章對新章），睇值唔值 US$9.99。
5. **簡體**：zh-Hans 喺讀嗰陣用 OpenCC 轉，應該照用；要跑 `check-hans` 確認新章冇漏轉字。

## 上線方法（建議）

- 加環境變數 `SYNTHESIS_BOOKS=1`，`cast/actions.ts` 讀佢決定傳唔傳 `synthesis: true`。要關就改返變數再 redeploy，唔使改 code。
- `/sample` 樣板書同 demo 照舊（樣板係即時砌，可另外決定用唔用新章）。
- 上線後抽幾本新書，中、簡、英、日四個版本逐頁睇。
